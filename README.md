# Customer Behavior Analysis using Python

## Project Overview
This project analyzes customer purchasing behavior using Python. The goal is to extract meaningful insights from retail sales data and understand patterns in customer segments, product categories, and sales trends.

## Dataset
Dataset: Global Superstore  
Records: 51,290 rows  
Columns: 27

The dataset contains information about orders, customers, sales, regions, product categories, and order dates.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

### 1. Top Customers by Sales
Identified the top 10 customers generating the highest revenue.

### 2. Customer Segment Analysis
Analyzed sales distribution across different customer segments:
- Consumer
- Corporate
- Home Office

### 3. Monthly Sales Trend
Performed time-series analysis to understand how sales change over time.

### 4. Product Category Analysis
Compared revenue generated by different product categories.

## Key Insights

- Consumer segment generates the highest revenue.
- Technology category has the highest sales among product categories.
- Monthly sales trend reveals fluctuations and growth patterns over time.
- A small number of customers contribute significantly to total revenue.
